# Python Calculator CLI

## Project Description
This project is a simple command-line calculator developed using Python. It performs basic mathematical operations based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Continuous calculator menu
- User-friendly interface
- Invalid input handling
- Division by zero protection
- Exit option

## Technologies Used
- Python
- Visual Studio Code
- Command Line Interface (CLI)

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python calculator.py
```
